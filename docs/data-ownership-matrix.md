# Data ownership matrix

Actual deployed app ownership is unverified. “Current” below identifies executable repository code, not production configuration.

| Entity / current table                                                      | Current writer                 | Target domain / authoritative owner                        | Application access                                                  | Migration / compatibility                                         |
| --------------------------------------------------------------------------- | ------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------- |
| Shipment / lex.shipments                                                    | Node shipment service          | core / platform Shipment service                           | Merchant own; Carrier assigned; LEX/NOC authorized operator         | Keep storage and UUID/tracking/status; canonical read projection  |
| ShipmentEvent / lex.shipment_history                                        | Node shipment transactions     | core / platform                                            | Same scoped shipment reads                                          | Keep unique shipment/version and history                          |
| Carrier / lex.carriers                                                      | Node admin/operator commands   | carrier / platform                                         | Admin/operator manage, carrier ownership checked by user_id         | Identity view only; no table move                                 |
| Command / lex.commands                                                      | Node command wrapper           | lex / orchestration command execution                      | Server-side commands only                                           | Preserve fingerprints and replay results; richer metadata later   |
| DomainEvent / lex.outbox                                                    | Node transactional emit        | integration / platform                                     | Admin/operator canonical event reads; subscribed external receivers | Preserve envelope/signatures; canonical projection only           |
| Subscription / lex.destinations                                             | Node admin                     | integration / platform                                     | Admin; worker reads                                                 | Keep secret references, exact legacy event selectors              |
| Delivery / lex.deliveries                                                   | Node worker/admin/receiver ack | integration / platform                                     | Operator reads; admin replays; owning platform acks                 | Keep IDs, leases and acknowledgment rules                         |
| Attempt / lex.delivery_attempts                                             | Node worker                    | integration / platform                                     | Protected delivery operations                                       | Preserve history                                                  |
| Approval / lex.wallet_approvals                                             | Node admin                     | billing / platform                                         | Admin command, external subscribed platform                         | No payment execution; no rename                                   |
| AuditEvent / lex.audit_log                                                  | Node transaction               | audit / platform                                           | No new public table access                                          | Preserve records; context expansion later                         |
| Worker / lex.worker_heartbeats                                              | Node worker                    | operations / platform                                      | Protected health                                                    | Preserve heartbeat contract                                       |
| Migration / lex.schema_migrations                                           | Migration runner               | platform infrastructure                                    | Deployment owner                                                    | Preserve checksums; never edit applied migration                  |
| Receiver inbox / lex_receiver.inbox                                         | Example independent receiver   | external app projection                                    | Receiver only                                                       | Not created in platform DB; receiver must be deployed separately  |
| Base44 Shipment, EventLog, PlatformConnection/Delivery and related entities | Retained Deno functions        | App-local until reconciled; target shipment truth platform | Independent Base44 apps                                             | Do not move/export production data automatically                  |
| Users/orgs, orders, assignments, trips, PUDO, incidents, expanded billing   | No Node tables                 | Respective platform domains                                | Future role/membership scoped APIs                                  | New schemas reserved only; requirements/data reconciliation first |

Base44/Rork keep UI preferences, device state and local read projections. They receive no direct database grants. Schema names alone do not provide tenant isolation. Table relocation and organization tenancy need separate, tested migrations.
